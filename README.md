# 台湾小说网（简体）书源

适用于安卓版「阅读」（Legado 3.0）。书源从[台湾小说网](https://m.xsw.tw/)获取内容，支持用简体书名搜索、加载分页目录，并将书名、作者、简介、章节名和正文转为简体。

## 网络导入

1. 复制下方整行地址。
2. 在「阅读」中进入 **我的 → 书源管理 → 右上角菜单 → 网络导入**。
3. 粘贴地址并确认，勾选 **台湾小说网（简体）**，保存并启用。

```text
https://raw.githubusercontent.com/Halley7025/yuedu/main/xsw-legado.json
```

## 本地导入

下载[书源 JSON 文件](https://raw.githubusercontent.com/Halley7025/yuedu/main/xsw-legado.json)到手机。在 **我的 → 书源管理 → 右上角菜单 → 本地导入** 中选择下载的 `xsw-legado.json`，勾选书源并保存。

## 开始阅读

回到书架，搜索 **万相之王**，选择来源为 **台湾小说网（简体）** 的结果，打开目录并点选章节。长篇小说的目录需要分多页加载，首次打开时可能要稍等。
